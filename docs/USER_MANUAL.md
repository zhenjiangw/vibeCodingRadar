# Vibe Coding 雷达 - 用户使用手册

## 概述

欢迎使用 **Vibe Coding 雷达**！这是一个帮助你发现并选择第一个编程项目的Web应用。

## 快速开始

### 访问应用

打开浏览器，访问：http://localhost:3000

### 首页概览

首页包含以下主要区域：

1. **顶部导航栏**：应用Logo、搜索框、收藏按钮
2. **欢迎区域**：应用介绍和关键数据
3. **分类筛选**：三个分类维度的筛选按钮
4. **项目列表**：展示筛选后的项目卡片
5. **明星项目**：GitHub热门项目展示

## 核心功能

### 1. 项目分类浏览

应用提供三个分类维度：

| 分类 | 图标 | 说明 |
|------|------|------|
| 最好玩 | 🎮 | 创意性与娱乐价值高的项目 |
| 最好用 | 🔧 | 实用性强、解决实际问题的项目 |
| 最好搓 | 👶 | 实现难度低、适合入门的项目 |

**使用方法：**
- 点击顶部分类按钮切换分类
- 点击"全部项目"查看所有项目

### 2. 项目搜索

**全局搜索功能：**

1. 在顶部搜索框输入关键词
2. 支持搜索项目名称、描述、技术栈
3. 搜索结果实时更新

**示例搜索：**
- `blog` - 搜索博客相关项目
- `React` - 搜索React项目
- `初级` - 搜索初级难度项目

### 3. 项目卡片查看

每个项目卡片包含：

- **项目名称**：点击可查看详情
- **项目简介**：不超过150字的描述
- **核心功能**：3-5个关键功能标签
- **难度标识**：初级（1星）/ 中级（2星）/ 高级（3星）
- **预计时间**：完成项目所需小时数
- **技术栈**：最多5个技术标签

### 4. 项目详情查看

点击项目卡片进入详情弹窗：

**详情内容：**
- **项目目标**：SMART原则描述的项目目标
- **技术栈建议**：主技术和辅助技术推荐
- **实施步骤**：至少5个关键步骤
- **预期成果**：功能成果和学习收获

**复制提示词：**
- 点击"复制开工提示词"按钮
- 提示词已格式化，可直接发送给AI助手
- 包含完整的项目规划信息

### 5. 收藏功能

**添加收藏：**
- 点击项目卡片上的❤️图标
- 收藏会自动保存到浏览器本地存储
- 刷新页面后收藏依然保留

**查看收藏：**
- 点击顶部导航栏的❤️图标
- 页面切换为收藏列表视图
- 点击"返回全部"回到完整列表

**取消收藏：**
- 在收藏列表中再次点击❤️图标
- 或在项目详情中点击❤️图标

### 6. 明星项目

**触发条件：**
- 向下滚动页面
- 当距离页面底部200px时自动加载
- 加载动画时长约500ms

**展示内容：**
- 项目名称和简介
- 24小时/7天star增长数
- GitHub链接
- 项目主语言

**交互功能：**
- 悬停时卡片缩放1.05倍，阴影加深
- 点击跳转到GitHub（新窗口打开）

## 使用场景

### 场景一：新手入门

1. 点击"最好搓"分类
2. 筛选出初级难度项目
3. 浏览项目卡片，选择感兴趣的项目
4. 点击查看详情，获取开工提示词
5. 将提示词发送给AI助手获取帮助

### 场景二：查找实用工具

1. 点击"最好用"分类
2. 使用搜索框搜索具体需求（如"天气"、"笔记"）
3. 查看项目详情了解功能
4. 收藏感兴趣的项目

### 场景三：探索创意项目

1. 点击"最好玩"分类
2. 浏览创意项目列表
3. 查看明星项目获取灵感
4. 点击GitHub链接查看原项目

### 场景四：学习新技术

1. 在搜索框输入技术名称（如"React"、"FastAPI"）
2. 找到使用该技术的项目
3. 查看项目详情了解技术应用
4. 按照步骤实现项目

## 常见问题

### Q: 收藏会同步到其他设备吗？

A: 当前收藏功能使用浏览器本地存储（localStorage），不会同步到其他设备。如需跨设备同步，需要登录账号功能，后续版本会考虑添加。

### Q: 明星项目数据多久更新一次？

A: 明星项目数据每天凌晨2点自动更新。

### Q: 如何获取更好的项目推荐？

A: 可以尝试：
- 使用多个关键词组合搜索
- 切换不同分类查看
- 关注明星项目获取灵感

### Q: 提示词格式适用于哪些AI助手？

A: 提示词采用标准化格式，适用于：
- ChatGPT / GPT-4
- Claude
- Gemini
- 豆包
- 文心一言
- 以及其他支持自然语言指令的AI助手
